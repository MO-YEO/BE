성과 및 개선 방향
구현 과정에서 얻은 기술적 성과와 협업 경험, 향후 발전 방향을 정리했습니다.
01
구현 결과
도메인 비즈니스 정책 구현
  • 지원 API 멱등성 보장
    (서비스 검증 + DB 유니크 복합키 이중방어)
  • 정원 충족 시 상태 자동 전환
    (ACCEPTED 인원 == totalHeadcount → CLOSED)
  • 피어 리뷰 접근 권한 정책
    (팀장 전용 지원자 평판 조회, 중복 차단)
  • 도메인별 통합 예외 핸들러 구성
    (@RestControllerAdvice, 표준 에러 포맷 통일)
02
협업 방식

    문서화 진행
  • Flyway 마이그레이션 19단계
    팀원 간 DB 스키마 충돌 완전 방지

    컨테이너화 → 환경 통일
  • EC2 · ngrok 외부 접속 테스트
